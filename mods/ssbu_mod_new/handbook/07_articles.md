- **General rule (A twice: G&W breath `+0x690`, Hero fireball `+0x1298`):** a donor weapon's native code may read the donor fighter's decoded vl.prc object from the manager at `*(main+0x52bb3b0)`. For a foreign owner that slot is null. Before shipping a cloned weapon with native code, scan its class vtable methods (RELA-relative entries around the slot the engine calls) and the initializer for `adrp 0x52bb000; ldr [..,#0x3b0]; ldr [..,#slot]` (`tools/scan_param_manager_reads.py <slot>`) and map every offset read through the donor's decoder. Tier-D: the slot is filled only while that fighter is loaded. The 0.18.1 `hero_object=present|absent` log line settles it.
